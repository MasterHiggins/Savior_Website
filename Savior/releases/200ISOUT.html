2.0.0 IS OUT

Article from Chris Higgins
(Developer)
This article does not contain spoilers

Hey all!

I started work on this project back in December 2023, and now Savior, after almost three years, is finished and fully playable.

I want to do something special, but I cannot do it in an article. In a few weeks, I'll be playing the game and posting my playthrough. Hopefully, some of you will pick up some lore, and be able to theorize on what Game 2 is.

GAME 2???

When I wrote the story of Savior back in January, it became clear to me that there would be a lot of details I would miss. So I decided to put that on hold, and instead write the outline for an entirely different game. If you play Savior first, then you'll be puzzled, but the goal is that when you play Game 2, all the pieces will fit together. Game 2 is going to be a much more ambitious project than Savior, but I can see bits of it in my head now.

I started work on the project file itself on August 5th, 2026, the day after Savior's final build was finalized. I haven't started full involved development yet like I did with Savior. I want to have a short break first. Instead, I've been working on some of the music tracks. The main theme is phenomenal, and I can't wait to share it.

I suspect I'll start full development in a few weeks, with a full preview in about a month and a half.

Because this is a game that runs parallel to Savior, it isn't Savior 0 or Savior 2, it is its own game that is cannon to Savior. It's hard to explain. I'll say more soon. Anyway, because it's in the same universe, this website will be used for both games. If you dig through files, you may have noticed I've been prepping various pages for this change, and it will happen when the first bit is ready. Hopefully this will be soon. For now though, Savior is the only game on this site, and anything Game 2 related will be done through this website and current methods.
