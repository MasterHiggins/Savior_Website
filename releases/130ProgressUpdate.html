Update 1.3.0 Progress

Article from Chris Higgins
(Developer)
THIS ARTICLE CONTAINS SPOILERS FOR THE GAME UP TO NOW

Let's just cut to the chase.

This is a really big update, 1.3.0 is. And because of it, extra care has been taken.

Let's think of it this way.

When comparing rooms, 1.1.0 added 23, 1.2.0 added 21, totalling to 44. 1.3.0 has added 42, nearly the same as the last two updates combined. When comparing this to release version 1.0.0, the "Part 2" updates have nearly reavhed the Part 1 room count, at 96, close to 1.0.0's 101.

Defining an area as an ancient module, this is the biggest area in the entire game.

As well, there are some features in this update that had to be extensively tested, and there are still bugs being found, however they aren't as prominent as before.

The current progress update is... 1.3.0 has a release date, and it is soon. Within days, there will be a presentation for this update. Please note, because the game is at a point where the story really matters, this presentation will not show any new gameplay. It will only reveal the content updates and some very vague screenshots. The release date will also come out. It's getting harder and harder not to spoil anything, so please bear with me.

Because 1.3.0 has some bugs, There is intended to be a 1.3.1 patch, which is already in the works. The current version testers are given is the one going out live very soon.

I'm sure that some of you are wondering about 2.0.0, now that 1.3.0 is finished.

The art is now in the works. The tile sets are underway and any other pieces that I will need are being made. Currently, I'm working on the final music track in the game. It's a very fitting end and I've been working on it for a few months. It's not as grand as the other tracks in this update, but it is a full circle track.

Other than that, I'm reluctant to reveal too much about Savior Update 2.0.0. The final presentation will barely focus on it for these reasons.

We really are in the end game now.

The story has almost been told.

The story has almost been finished.

But whose to say? The future was never written.

And thus concludes the Story of Savior.
